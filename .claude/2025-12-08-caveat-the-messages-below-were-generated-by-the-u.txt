     lrgsglib Documentation
     ======================
     **lrgsglib** is a Python library implementing the theoretical tools of
     the **Laplacian Renormalization Group for Signed Graphs**. It provides
     utilities for building signed networks, running renormalization flows,
     and simulating statistical physics models such as the Ising model,
     contact process, and voter dynamics.
     The library combines high-level Python interfaces with
     performance-critical C/C++ extensions for efficient simulations on
     large networks.
     .. note::
