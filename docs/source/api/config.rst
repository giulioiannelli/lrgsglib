config - Configuration and Program Arguments
=============================================

The ``config`` module provides configuration management, error handling, environment variables, and program argument definitions.

.. currentmodule:: lrgsglib.config

Overview
--------

This module includes:

- **Constants**: Project-wide constants and default values
- **Environment**: Environment variable management (paths, build configuration)
- **Error Handling**: Custom exceptions and warnings
- **Functions**: Configuration utility functions
- **Program Arguments**: Command-line argument definitions for various graph types and simulations
