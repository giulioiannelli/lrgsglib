utils - Utility Functions
=========================

The ``utils`` module provides utility functions for spectral analysis, basic operations, reconstruction algorithms, and tools for statistical physics simulations.

.. currentmodule:: lrgsglib.utils

Overview
--------

This module is organized into several submodules:

- **lrg**: Laplacian Renormalization Group utilities (spectral analysis, clustering, quantum operators)
- **basic**: Basic mathematical operations (linear algebra, calculus, probability, geometry, I/O)
- **recon**: Reconstruction algorithms for network inference
- **tools**: Helper functions and utilities
- **statsys**: Statistical physics simulation utilities
