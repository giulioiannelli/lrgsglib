Build System
============

This document describes the build system, Makefile structure, environment
configuration, and dependency management in lrgsglib.

Overview
--------

lrgsglib uses a Makefile-based build system that:

1. Compiles C/C++ extensions
2. Generates environment configuration files
3. Sets up conda environment
4. Creates required directories

Quick Reference
---------------

.. code-block:: bash

   # Full build (configuration + C compilation)
   make all

   # Build with submodule configuration
   make all LRGSG_LLIB=$(pwd)/.. CONDA_ENV_NAME=your_env

   # C compilation only
   make c-make

   # Clean and rebuild
   make clean && make all

   # Just configure paths
   make basic-config

   # Configure conda environment
   make conda-config

Makefile Structure
------------------

The main Makefile includes modular configuration files:

.. code-block:: text

   lrgsglib/
   ├── Makefile                  ← Main build file
   └── build/
       ├── lrgsg-paths.mk        ← Path definitions
       ├── cconfig.mk            ← C compiler configuration
       ├── cprogn.mk             ← C program definitions
       └── conda-config.mk       ← Conda environment setup

Main Makefile Targets
~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - Target
     - Description
   * - ``all``
     - Full build: config + C compilation
   * - ``full-config``
     - ``basic-config`` + ``conda-config``
   * - ``basic-config``
     - ``path-config`` + ``env-config`` + ``create-dirs``
   * - ``c-make``
     - Compile all C programs
   * - ``clean``
     - Remove build artifacts

Path Configuration
------------------

Paths are defined in ``build/lrgsg-paths.mk``:

.. code-block:: make

   # Project root (lrgsglib directory)
   LRGSG_ROOT := $(shell pwd)

   # Library base directory (overridable)
   LRGSG_LLIB ?= $(LRGSG_ROOT)

   # Path definitions: NAME:dirname:PARENT
   LRGSG_PATHS := \
       BUILD:build:ROOT \
       DATA:data:LLIB \
       IPYNB:ipynb:LLIB \
       LOG:.log:LLIB \
       SRC:src:ROOT \
       TEST:test:ROOT \
       ...

**Key paths:**

- ``LRGSG_ROOT`` - Library root directory (lrgsglib/)
- ``LRGSG_LLIB`` - Outer project root (for submodule usage)
- ``LRGSG_DATA`` - Data storage directory
- ``LRGSG_IPYNB`` - Notebooks directory
- ``LRGSG_CCORE_BIN`` - Compiled C binaries

Standalone vs. Submodule Builds
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Standalone usage** (lrgsglib is the main project):

.. code-block:: bash

   cd lrgsglib
   make all

All paths are relative to ``lrgsglib/``.

**Submodule usage** (lrgsglib inside another project):

.. code-block:: bash

   cd lrgsglib
   make all LRGSG_LLIB=$(pwd)/..

Paths for data, notebooks, and logs are relative to the outer project:

- ``data/`` → ``outer-project/data/``
- ``ipynb/`` → ``outer-project/ipynb/``
- ``.log/`` → ``outer-project/.log/``

Environment Configuration
-------------------------

The build system generates environment configuration files:

.env File
~~~~~~~~~

Generated by ``dotenv-file`` target:

.. code-block:: bash

   # .env file contents
   LRGSG_ROOT=/path/to/lrgsglib
   LRGSG_DATA=/path/to/data
   LRGSG_IPYNB=/path/to/ipynb
   LRGSG_LOG=/path/to/.log
   LRGSG_CCORE_BIN=/path/to/Ccore/bin
   ...

Loaded automatically via ``python-dotenv`` in Python code.

lrgsg_env.py
~~~~~~~~~~~~

Generated Python configuration file:

.. code-block:: python

   # src/lrgsglib/config/lrgsg_env.py
   from pathlib import Path

   LRGSG_ROOT = Path("/path/to/lrgsglib")
   LRGSG_DATA = Path("/path/to/data")
   LRGSG_CCORE_BIN = Path("/path/to/Ccore/bin")
   # ...

Imported by the library to access paths.

C Compiler Configuration
------------------------

Defined in ``build/cconfig.mk``:

.. code-block:: make

   GCC = gcc
   CFLAGS = -O3 -march=native -Wall
   LMFLAG = -lm
   ALLFLAGS = $(CFLAGS) -DSFMT_MEXP=19937

**Compiler flags:**

- ``-O3`` - Maximum optimization
- ``-march=native`` - Optimize for current CPU
- ``-Wall`` - Enable all warnings
- ``-DSFMT_MEXP=19937`` - SFMT period parameter

C Program Definitions
---------------------

Defined in ``build/cprogn.mk``:

.. code-block:: make

   # Program list
   PROGS = $(LRGSG_CCORE_BIN)/IsingSimulator0 \
           $(LRGSG_CCORE_BIN)/IsingSimulator1b \
           $(LRGSG_CCORE_BIN)/IsingSimulator3b \
           $(LRGSG_CCORE_BIN)/IsingSimulator4b \
           $(LRGSG_CCORE_BIN)/VoterSimulator0 \
           $(LRGSG_CCORE_BIN)/VoterSimulator1 \
           $(LRGSG_CCORE_BIN)/ContactSimulator1c \
           ...

   # Source file paths
   PATH_SRCC_FILES = $(LRGSG_LIB_CCORE)/LRGSG_utils.c \
                     $(LRGSG_LIB_CCORE)/sfmtrng.c
   PATH_SFMT_FILES = $(LRGSG_CCORE_SFMT)/SFMT.c

Pattern Rules
~~~~~~~~~~~~~

The Makefile uses pattern rules for similar programs:

.. code-block:: make

   # Generic IsingSimulator pattern
   $(LRGSG_CCORE_BIN)/IsingSimulator%: \
           $(LRGSG_RBIM_SIMC)/IsingSimulator%.c \
           $(PATH_SRCC_FILES) \
           $(PATH_SRCC_RBIM) \
           $(PATH_SFMT_FILES) \
           $(PATH_SRCC_BINDYNSYS)
       @printf "Compiling IsingSimulator%s...\n" "$*"
       $(GCC) $(ALLFLAGS) -o $@ $^ $(LMFLAG)

   # Simulated Annealing variants (need LRGSG_sa)
   $(LRGSG_CCORE_BIN)/IsingSimulator3b: \
           $(LRGSG_RBIM_SIMC)/IsingSimulator3b.c \
           $(PATH_SRCC_FILES) \
           $(PATH_SRCC_RBIM) \
           $(PATH_SRCC_SA) \
           $(PATH_SFMT_FILES) \
           $(PATH_SRCC_BINDYNSYS)
       @printf "Compiling IsingSimulator3b (SA)...\n"
       $(GCC) $(ALLFLAGS) -o $@ $^ $(LMFLAG)

Conda Environment
-----------------

Configured in ``build/conda-config.mk`` and ``lrgsgenv.yml``:

.. code-block:: bash

   # Create environment from YAML
   conda env create -f lrgsgenv.yml

   # Activate
   conda activate lrgsgenv

   # Configure via Makefile
   make conda-config CONDA_ENV_NAME=lrgsgenv

**Key dependencies:**

- ``numpy``, ``scipy``, ``networkx`` - Core scientific computing
- ``matplotlib``, ``pandas`` - Data analysis
- ``pybind11`` - C++ bindings
- ``cupy`` - GPU acceleration (optional)
- ``graph-tool`` - Advanced graph algorithms (from conda)

Python Package Installation
---------------------------

After building, install the Python package:

.. code-block:: bash

   # Editable installation (development)
   pip install -e .

   # With optional dependencies
   pip install -e ".[dev,docs]"

Optional extras (from ``pyproject.toml``):

- ``dev`` - Development tools (black, isort, mypy, pytest)
- ``docs`` - Documentation tools (sphinx, sphinx-rtd-theme)

Build Workflow
--------------

Complete build from scratch:

.. code-block:: bash

   # 1. Clone repository
   git clone https://github.com/giulioiannelli/lrgsglib
   cd lrgsglib

   # 2. Initialize submodules
   git submodule init
   git submodule update

   # 3. Create conda environment
   conda env create -f lrgsgenv.yml
   conda activate lrgsgenv

   # 4. Build everything
   make all

   # 5. Install Python package
   pip install -e .

   # 6. Verify
   pytest test/

For submodule usage:

.. code-block:: bash

   # Inside outer project
   cd lrgsglib
   make all LRGSG_LLIB=$(pwd)/.. CONDA_ENV_NAME=outer_env_name
   pip install -e .

Rebuilding After Changes
------------------------

**After modifying C code:**

.. code-block:: bash

   make c-make

**After modifying paths or adding new programs:**

.. code-block:: bash

   make clean && make all

**After pulling updates:**

.. code-block:: bash

   git pull
   make clean && make all
   pip install -e .

Directory Creation
------------------

The build system creates required directories:

.. code-block:: make

   DIRS_TO_MAKE = $(LRGSG_DATA) $(LRGSG_CCORE_BIN)

   create-dirs:
       @mkdir -p $(DIRS_TO_MAKE)

Troubleshooting
---------------

**"Command not found: gcc"**

Install GCC compiler:

.. code-block:: bash

   # Ubuntu/Debian
   sudo apt-get install build-essential

   # macOS
   xcode-select --install

**"Cannot find SFMT.h"**

Ensure submodules are initialized:

.. code-block:: bash

   git submodule init
   git submodule update

**"Permission denied" on scripts**

.. code-block:: bash

   make chmod-scripts

**Conda environment not found**

Create the environment first:

.. code-block:: bash

   conda env create -f lrgsgenv.yml
   conda activate lrgsgenv

**Path configuration issues**

Regenerate configuration:

.. code-block:: bash

   make clean
   rm .env src/lrgsglib/config/lrgsg_env.py
   make all

Debug Build
-----------

To see what the Makefile is doing:

.. code-block:: bash

   # Print paths
   make echo-paths

   # Dry run (show commands without executing)
   make -n c-make

   # Verbose compilation
   make c-make VERBOSE=1
